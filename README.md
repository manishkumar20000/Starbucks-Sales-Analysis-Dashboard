# ☕ Starbucks Sales Analysis Dashboard

## 📊 Project Overview

The **Starbucks Sales Analysis Dashboard** is an interactive Power BI dashboard developed to analyze Starbucks sales data and generate meaningful business insights.

The project transforms raw sales data into an interactive and easy-to-understand dashboard using **data cleaning, transformation, modeling, KPI creation, and data visualization** techniques.

## 🎯 Project Objectives

* Analyze overall Starbucks sales performance
* Track important business KPIs
* Identify sales trends and patterns
* Analyze product category performance
* Compare sales across different time periods
* Create an interactive dashboard for business analysis

## 📈 Key Performance Indicators (KPIs)

* **Total Sales**
* **Total Orders**
* **Total Quantity Sold**
* **Average Order Value**
* **Sales by Product Category**
* **Monthly Sales Trends**

## 🛠️ Tools & Technologies

* **Power BI**
* Power Query
* DAX
* Data Modeling
* Data Visualization

## 🔍 Key Features

### Interactive Dashboard

Users can interact with the dashboard using filters and slicers to explore different aspects of the sales data.

### KPI Analysis

Important business metrics are displayed clearly to provide a quick overview of sales performance.

### Sales Analysis

The dashboard provides insights into sales trends, product categories, and overall business performance.

### Data Visualization

Different charts and visual elements are used to present complex data in a simple and understandable way.
